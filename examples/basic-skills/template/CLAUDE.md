# Agent guidance (basic-skills example template)

A small, everyday profile with three basic skills seeded in. Replace this file and the
`skills/` directory with your own.

- You are running in an isolated container; the working directory is the project.
- Keep changes scoped to the task, and explain what you did and why.
- Prefer the available skills (`run-tests`, `git-commit`, `review-diff`) for those tasks.
